# Phinix Media · Beauty Booking System™

Editorial German landing page for beauty studio marketing. Five original AI-generated macro photographs, self-hosted fonts, responsive layouts, scroll reveals, reduced-motion support, interactive content examples, native accessible dialogs and FAQ accordions.

## Preview

Run `python3 -m http.server 4173 --directory dist`, then open http://localhost:4173.
No build dependencies required.

## SEO

German page copy, semantic headings, descriptive image alt text, title and description, canonical URL, Organization/WebSite/FAQPage structured data, robots.txt and sitemap.xml.
